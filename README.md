# SoniX

## See the Other Side of Social

SoniX is a premium, frontend-only social experience built around **decisions, not posts**. The working concept, **Perspective**, asks a simple question: "See how others would choose."

Instead of scrolling through profiles, a visitor encounters a familiar situation, makes a blind first choice, explores the reasoning behind other choices, and decides whether their own perspective has shifted.

**Choose > Reveal > Explore > Reconsider > Reflect.**

## Running Locally

Requirements: Node.js 20.19+ or 22.12+ and npm.

```sh
npm install
npm run dev
```

Create and preview the static production build:

```sh
npm run build
npm run preview
```

The production output is in `dist/`. Deploy the entire directory, including its public image and SVG assets, to a static host. There are no environment variables, credentials, API keys, or services to configure.

## Frontend Only

This is an intentional product prototype, not a simulated backend application.

- No application backend, API routes, authentication, database, server actions, or server-side persistence.
- No calls to an application API. Scenario selection, filtering, choices, comparisons, details, and reflections run locally.
- The only persistence is optional browser `localStorage`, under `sonix-journey-v1`.
- If local storage is unavailable or contains invalid data, the app falls back to an in-memory journey.
- The 160 anonymous perspectives are original, fictional, curated examples. They are not live user submissions or research data.
- Distribution charts describe the eight local perspectives plus the visitor's choice. They do not claim to represent public opinion.
- Reflection messages are predefined editorial content, not generated by an AI service.
- The pricing section describes this free prototype. There is no paid tier or fake checkout.
- The reflection-style quotes are clearly labeled illustrative, not customer endorsements.

The supplied project environment uses **React + Vite**, so the implementation preserves that entry point rather than adding a Next.js server. It is a completely static client application.

## Product Experience

### Discover

An editorial landing page with a sticky navigation, an original full-bleed circular-identity illustration, interactive how-it-works steps, a featured scenario, topic discovery, benefit accordions, illustrative reflections, free access, native FAQ disclosures, and a closing invitation.

### Choose

One large circular situation, a category, context, and four clear answers. The reveal action remains disabled until a choice is selected. Radio-style controls support arrow keys, Home, End, Space, and Enter.

### Reveal and Explore

A short reveal introduces a choice distribution and eight anonymous perspective circles. Opening a circle shows the full reasoning, context tags, and a direct comparison with the visitor's original answer. Explored perspectives are marked without introducing likes or popularity scores.

On small screens the circular perspectives become a readable, swipeable collection with working previous/next controls, rather than miniature desktop cards.

### Reconsider

The visitor can keep their answer, choose a different option, or remain unsure. Choosing to change requires selecting a new answer before continuing.

### Reflect

Before and after appear as linked circular states. The copy, current answer, and comparison respond to the actual decision. The chart uses exact proportions and rounds only the displayed percentage, so equally sized groups stay visually equal. Uncertainty remains a valid state rather than a forced answer.

### Explore

Browse 20 situations across eight categories. Category selection, case-insensitive search, empty-state recovery, local pagination, and Surprise me all work without network requests. Mobile has a native topic selector and full-size scenario circles to preserve readability.

### My Journey

Resume an unfinished situation, revisit a completed reflection, or reset the entire local journey with confirmation. Completing the same scenario again replaces its previous reflection, keeping one current reflection per situation.

Each situation has four choices and eight varied, contextual responses, for **160 perspectives** in total. Responses explore practical, emotional, cautious, empathetic, analytical, and adventurous ways of thinking. They are interleaved, not ranked.

To add a situation, add a typed seed with a unique ID, category, title, context, four choice labels, reasoning grouped by option, and a reflection insight. Stable anonymous identities and response IDs are constructed locally.

```text
    ReflectionPanel.tsx         Dynamic before/after and editorial insight

  images/perspective-world.png  Original compressed hero illustration

```

The state machine has four stages: `choose`, `perspectives`, `reconsider`, and `reflection`. The initial answer is mutable only while choosing. The reveal transition requires a selected option, and completing a reflection requires the reconsider stage. The React UI reads this state rather than exposing artificial loading or backend placeholders.

## Design Decisions

- Circular interaction surfaces communicate that choices and people are connected, not ranked in a feed.
- Warm mint, forest ink, and small clay/lilac accents create a calm visual hierarchy rather than a notification-driven environment.
- The brand is a hero-level signal, supported by one integrated image plane and one clear primary action.
- The social action is understanding a reason and reconsidering, not liking, commenting, or following.
- Motion is purposeful: staggered hero entry, gentle ambient artwork, scroll reveals, selection feedback, and a reveal-to-reflection transition.
- Responsive layouts change composition rather than shrinking everything. Large scenario circles, native mobile filtering, and swipeable perspectives keep the experience legible.

## Accessibility and Performance

- Semantic navigation, headings, buttons, fieldsets, native details/summary, and labels.
- Visible keyboard focus, roving radio-group focus, Escape-to-close, focus trapping, restored focus, and an inert background behind dialogs.
- A working skip link that does not accidentally change the application route.
- Motion respects the operating system's reduced-motion preference through `MotionConfig`, `useReducedMotion`, and CSS.
- No profile photography or avatar requests; identities are lightweight, local SVG illustrations.
- The hero is an approximately 80 KB local asset, explicitly sized and prioritized to avoid layout shifts.
- Lucide icons are imported individually. The decision experience has a lazy component boundary; the supplied single-file production plugin can inline that boundary for static deployment.
- DM Sans and Manrope are optional Google Fonts. Local sans-serif fallbacks preserve the entire experience if fonts are blocked or offline.
- After the initial frontend has loaded, every core interaction continues without a network request to an application service.

## Judge Walkthrough

1. Open Discover. Explain: "SoniX connects people through choices, not posts."
2. Select Start exploring. Choose A before seeing anyone else's response.
3. Reveal perspectives. Open one response that chose A and another that chose C.
4. Compare their reasoning, not their popularity. Return to all perspectives.
5. Select Reconsider my answer, choose "I see a different way now," and select C.
6. Open the reflection to see the real before/after state and updated distribution.
7. Open My journey to see the saved reflection.
8. Close the dialog, open Explore, and select another category.
9. Optionally demonstrate browser-local persistence and the confirmed reset action.

**The innovation:** "The social interaction is not following people. It is seeing how other people think, then deciding whether their perspective changes yours."

Connection comes from a shared situation. Communication comes from contextual reasoning. Discovery comes from encountering another angle. Participation comes from choosing, exploring, and reconsidering.
